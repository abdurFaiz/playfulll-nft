# 🌌 Orbis NFT

> _Beyond earth and its familiar boundaries._

A space-themed NFT collection landing page built with React, TypeScript, and Tailwind CSS. Features immersive full-screen video backgrounds, a liquid glass UI aesthetic, and a curated gallery of space object NFTs with rarity scores.

---

## ✨ Features

- Full-screen video hero, about, and CTA sections
- Liquid glass morphism UI components
- NFT collection grid with rarity scores
- Responsive layout for all screen sizes
- Anton + Condiment Google Fonts pairing
- Social links (Mail, Twitter/X, GitHub)

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
